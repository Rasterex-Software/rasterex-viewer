# Version 2.2.8 Change Notes

## Status

Prepared locally after user acceptance of pasted RXML import in Modern and
Legacy. Publication pending.

## Added APIs

`viewer.annotations.load(options)` returns a typed `LoadAnnotationsResult`
for the active document. Call after `fileReady`. The package exports the
options, result and import policy types.

JSON accepts native or flat records, arrays, `{ items }` snapshots and JSON
text. Rasterex XML accepts inline content or an explicit HTTP(S) URL. The SDK
defaults to merging and skipping matching JSON GUIDs. Set
`replacePolicy: "replace"` to replace matching JSON GUIDs in merge mode or
`mode: "replaceAll"` for validated inline content. XML URLs are merge only.
XML duplicate behavior follows the native loader. Canvas import is not
transactional.

`measurementScalePolicy` defaults to `"currentPage"`. Use `"preserve"` to
retain valid saved calibration snapshots. `emitCreated` defaults to true and
requests native creation callbacks. Each call accepts optional `requestId`
and `timeoutMs`. The default timeout is the viewer's `commandTimeoutMs`.

## Protocol and compatibility

Wraps the existing Canvas `loadAnnotations` / `annotationsLoaded` contract
and matches receipts by request ID. One import can be pending per viewer.
The SDK preserves Canvas's `loaded`, `skipped` and `total` counts. The
`loaded` count can include an existing matching GUID. Refresh the annotation
list to verify the actual records. Some older Canvas builds may omit the
default scale policy on the receipt. An explicit `preserve` request requires
confirmation. Capability negotiation and the protocol version stay the same.

## Errors and lifecycle

Existing error codes cover viewer readiness, invalid input or receipts, native
reason, transport failure and timeout. A timeout leaves the outcome unknown.
Check the records and reconnect before another import. The SDK releases
listeners on disconnect or timeout and does not retry imports automatically.

## Local test parent

**Paste Rasterex XML (local URL)** serves pasted RXML in memory for two minutes
on the loopback Canvas proxy, then sends the URL through the existing SDK
import API in merge mode. The server limits each paste to 2 MiB. This is a
local example feature. The direct inline broker command timed out on the
tested Canvas build. The URL loader imported the pasted sample Area in both
Legacy and Modern, and the user confirmed the workflow in both modes.

The parent can also import inline JSON, copy current records into the import
input and try an existing XML URL. See
`examples/annotation-tools/ANNOTATION-IMPORT.md` for the manual checks.

## Migration and security

Existing integrations require no changes. After release, update to 2.2.8 to
use the new API. The SDK introduces no runtime dependency and retains the
broker's source and origin checks. The example's paste server remains local
to the development harness.

## Verification

Local JSON smoke tests verified merge, duplicate skip and explicit replace-all.
Browser testing verified pasted RXML in both appearance modes and checked the
annotation list for the imported Area. A complete calibration round trip
remains a separate manual check.
