# Version 2.2.2 Change Notes

## Status

In progress

## Summary

Complete the npm-only A5 compare workflow while carrying forward the A1 and A3
release context: hosted evaluation is Sandbox-only, readiness is bounded and
cancellable, and normal comparison is promise-based.

## Added APIs

`viewer.compare.compare(...)` returns `Promise<ComparisonResult>`.

## Changed APIs

Evaluation runs only when `viewerUrl` uses the hosted Rasterex Sandbox origin.
Client-owned and self-hosted Canvas URLs skip hosted evaluation.

Viewer readiness defaults to a 60-second timeout. Hosts can override it with
`timeoutMs` and cancel it with an `AbortSignal`.

Normal comparison resolves after the payload-bearing `comparisonComplete` and
following `progressEnd` events. It rejects on Canvas comparison errors,
timeout, disconnect, or invalid input. `align(...)` and `save(...)` remain
unchanged.

## Removed APIs

None.

## Protocol Changes

No Canvas broker or Protocol V1 changes. The SDK uses the existing Canvas
comparison commands and events.

## Compatibility Changes

Self-hosted and air-gapped Canvas deployments no longer require network access
to the hosted evaluation API for SDK readiness. No minimum Canvas version
change is required.

## Error Code Changes

No new error codes. Readiness uses `CANVAS_READY_TIMEOUT` and
`VIEWER_NOT_READY`; compare timeouts use the existing `COMMAND_TIMEOUT` error.

## Diagnostics Changes

None.

## Repository CI/CD Changes

Added ESM CI on pull requests and main across Node 20.19.0, 22.12.0, and 24.
Checks validate version consistency, build, unit tests, source limits, packed
files, fresh tarball installation, root/subpath imports, and NodeNext/Bundler
type resolution. Added stable-tag publishing with main ancestry and version
checks, npm OIDC, and the npm-production environment. Publication defaults to
disabled until NPM_PUBLISH_ENABLED is true and administrator setup is complete.
See docs/planning/npm-ci-cd.md. No SDK version bump or runtime changes are
introduced by this repository automation work.

## Framework Adapter Changes

None. These changes are implemented in the framework-independent core SDK.

## Air-Gap and Security Impact

The SDK skips hosted evaluation for client-owned Canvas URLs. No new runtime
dependency, CDN reference, telemetry, or Canvas application code is added.

## Migration Notes

Existing `await viewer.ready()` calls remain valid. Applications may optionally
provide `timeoutMs` or an `AbortSignal`.

Normal comparison can now be awaited:

```ts
const result = await viewer.compare.compare({
  fileA: "first.dwg",
  fileB: "second.dwg",
});
```

No migration is required for `align(...)` or `save(...)`.

## Test and Verification Notes

Run the production build, full test suite, source-line check, and diff checks.

## Known Risks

The hosted Sandbox is identified by origin matching. A future product decision
may replace this with an explicit deployment preset or another marker.
