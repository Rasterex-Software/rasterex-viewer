# Version 2.1.6 Change Notes

## Status

In progress

## Summary

Add view synchronization snapshot alignment and update the React integration guidance for the published 2.1.5 API line.

## Added APIs

`viewer.viewSync.getSnapshot({ groupId, timeoutMs? })` and `viewer.viewSync.applySnapshot(snapshot, { timeoutMs? })`. `ViewSyncConfiguration` accepts `enabled?` so hosts can configure identity and mode while keeping live events disabled during document alignment. View sync pan state exposes `coordinateMode` as `"delta" | "absolute"`.

## Changed APIs

No removals. The React guide now targets SDK `2.1.6` and documents disabled configuration, snapshot alignment, and `referrerPolicy="origin"` for cross-origin Canvas embeds.

## Removed APIs

None.

## Protocol Changes

No Protocol V1 envelope change. The SDK maps Canvas broker snapshot messages `getViewSyncSnapshot`, `viewSyncSnapshot`, `applyViewSyncSnapshot`, and `viewSyncSnapshotApplied`.

## Compatibility Changes

Canvas must support the snapshot broker messages. Snapshot alignment requires matching pages and compatible viewer geometry; it does not change page or rotation. Canvas page indexes may be zero-based (`page: 0`). No minimum Canvas version is defined.

## Error Code Changes

No new error codes. Invalid snapshot results and command failures use the existing SDK command error. Timeouts use `COMMAND_TIMEOUT`; disconnects use `VIEWER_NOT_READY`.

## Diagnostics Changes

Existing Canvas broker command and event diagnostics cover the new message types.

## Framework Adapter Changes

None. The React documentation uses the framework-independent core API.

## Air-Gap and Security Impact

No new dependencies, URLs, telemetry, or CDN behavior. Existing origin and iframe-source validation remains active. Cross-origin hosts must configure `parentOrigin` and `referrerPolicy="origin"` as documented.

## Migration Notes

Install `@rasterex/viewer@2.1.6`. Configure each viewer with `enabled: false`, wait for `documents.open()` / `fileReady`, align with `getSnapshot()` and `applySnapshot()`, then enable live sync. Keep live relay disabled if alignment fails.

## Documentation Notes for Docs Agents

Use `docs/live-npm/view-sync/react-host.md` as the complete React integration guide. It includes the snapshot alignment lifecycle, four modes, origin requirements, and failure handling.

## Test and Verification Notes

Run `npm run build`, `npm run check:source-lines`, and `node --test test/view-sync.test.mjs`. The snapshot validator accepts zero-based page indexes.

## Known Risks

Different drawings may not share compatible raw offsets. Canvas may omit request IDs on live apply results; snapshot and configuration operations require matching request IDs.
