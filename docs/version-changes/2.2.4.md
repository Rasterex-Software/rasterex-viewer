# Version 2.2.4 Change Notes

## Status

In progress — prepared for publication; not published.

## Summary

Improve npm discoverability and integration documentation for the Rasterex
JavaScript and TypeScript CAD, DWG, and PDF viewer SDK. npm registry inspection
on 2026-10-12 confirmed `2.2.3` is already published and `2.2.4` is available,
so this metadata/documentation update uses the next patch version.

## Added APIs

None.

## Changed APIs

No API behavior changes. `SDK_VERSION` now reports `2.2.4`, aligned with
`package.json` and both root version fields in `package-lock.json`.

## Removed APIs

None.

## Protocol Changes

No Canvas broker commands, payloads, events, or Protocol V1 changes.
No protocol version bump is required.

## Compatibility Changes

Existing SDK integrations remain compatible. Canvas version requirements,
capability requirements, and compatible/degraded/incompatible behavior are
unchanged. The SDK-local compatibility matrix uses the updated `SDK_VERSION`.

## Error Code Changes

None.

## Diagnostics Changes

No diagnostic event changes. SDK version information reports `2.2.4`.

## Framework Adapter Changes

None. React documentation uses the existing framework-independent core SDK.

## Air-Gap and Security Impact

No runtime network behavior, dependencies, telemetry, CDN usage, origin
validation, or mixed-content behavior changes. New links occur only in
documentation. Hosted Sandbox and self-hosted evaluation behavior is unchanged.

## Migration Notes

No code migration is required. Install `@rasterex/viewer@2.2.4` after publication
to receive the updated package README and description.

## Documentation Notes for Docs Agents

- Package description and README explicitly identify JavaScript and TypeScript
  support, CAD/DWG/DXF/DGN/IFC/PDF workflows, and self-hosted deployment.
- README states that TypeScript declarations are bundled without a separate
  `@types` package, and links to npm, the Rasterex product site, and guides.
- React guide includes DWG document-opening options and lifecycle guidance;
  drawing-comparison guide explicitly addresses JavaScript and TypeScript.
- New self-hosted guide covers deployment prerequisites, document opening,
  startup failures, cleanup, and air-gapped deployment limits.
- Discoverability plans use `https://docs.rasterex.com/` consistently.
- Selected public guides/plans are allowed through `.gitignore` so their
  repository links can ship. Other local documentation remains excluded.
- Task 30 records website publishing, indexing/redirect checks, and Search
  Console/npm discovery measurement as outstanding external work.

## Test and Verification Notes

`npm run check` passed after the bump: version consistency, package metadata,
build, all 35 automated tests, source-line limits, packed package contents,
fresh ESM consumer installation, and TypeScript declaration resolution.
`git diff --check` also passed.
New self-hosted and React/DWG example snippets previously passed strict
TypeScript compilation against the built SDK declarations.

## Known Risks

Website documentation publishing, redirects, canonical tags, sitemap/indexing
controls, and Search Console measurement have not been completed here.
README repository guide links become available when these files reach the
public main branch. No search ranking improvement is guaranteed or measured.
Publishing must occur only after the repository's release checks and process.
