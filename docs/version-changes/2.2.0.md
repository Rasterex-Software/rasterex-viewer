# Version 2.2.0 Change Notes

## Status

In progress

## Summary

Add the framework-independent `viewer.clientCompare` API for Canvas client-side comparison.

## Added APIs

Add `ClientCompareApi` as `viewer.clientCompare` with `create`, `setOpacity`, `setCommonLevel`, `startAlign`, `close`, and typed event subscriptions. Export the client comparison request, result, failure, and event types.

## Changed APIs

None. Existing `viewer.compare` server-side compare and align APIs remain unchanged.

## Removed APIs

None.

## Protocol Changes

No Protocol V1 envelope change. The SDK maps the client comparison Canvas broker messages documented in `CLIENT_COMPARE_POSTMESSAGE_API.md`.

## Compatibility Changes

Canvas must support the client comparison broker messages. No minimum Canvas version or capability name is defined by the source document; unsupported deployments expose Canvas failure or command timeout.

## Error Code Changes

No new SDK error codes. Input validation, Canvas failures, timeouts, and disconnects use existing SDK command errors.

## Diagnostics Changes

Existing Canvas broker command and event diagnostics include client comparison message types.

## Framework Adapter Changes

None. The API is framework-independent.

## Air-Gap and Security Impact

No new dependencies, URLs, telemetry, or CDN usage. Existing origin and iframe-source validation remains active.

## Migration Notes

Use `viewer.clientCompare` for client-side comparison. Continue using `viewer.compare` for server-side comparison files. Call `create()` after `viewer.ready()`, then use property commands or interactive alignment.

## Documentation Notes for Docs Agents

Use `docs/live-npm/compare/client-compare.md` and the Canvas contract document for public usage and broker details.

## Test and Verification Notes

Run the build, source-line check, and focused client compare tests.

## Known Risks

Canvas source identity resolution, alignment timeout behavior, and client comparison capability reporting remain Canvas deployment responsibilities.
